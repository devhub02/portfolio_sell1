# Devendra Kumar — Portfolio

A single-page dark portfolio landing page for **Devendra Kumar** — Mechanical Engineer, product developer and founder based in Gaya, India.

## Features

- Loading screen with animated counter and rotating words
- Hero with HLS background video, floating navbar and GSAP entrance animation
- Selected Work bento grid, Resume section (experience, education, skills), Journal and Stats
- Scroll-driven parallax "Explorations" gallery with lightbox
- Contact footer with looping marquee and flipped HLS video
- Smooth-scroll navigation and page transitions

## Tech stack

React · Vite · TypeScript · Tailwind CSS · GSAP · Framer Motion · hls.js · React Router

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run preview  # preview the production build
```

## Customising

All personal content (name, contact details, social links, skills, projects) lives in [`src/data.ts`](src/data.ts).
